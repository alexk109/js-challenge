# Sun Devil Semiconductor

Shared repository of the Sun Devil Semiconductor club.

Project: [Jane Street protocol emulator ASIC competition](https://blog.janestreet.com/protocol-emulator-asic-competition/).

| dir | contents |
|---|---|
| `design/hdl` | RTL |
| `design/phy` | physical design |
| `verification` | testbenches, VIP, formal |
| `firmware` | firmware |
| `simulator` | simulator (`make -C simulator ui`) |
| `scripts` | common scripts (`scripts/setup.sh`) |
| `tools` | downloaded tool binaries (gitignored) |
| `docs` | documentation |
